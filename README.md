> ## ⚠️ 内容提示(阅读前请知悉)
> **本作品是一部虚构的恐怖互动小游戏(心理恐怖问卷)。**
> 包含:突发惊吓(全屏红字、屏幕抖动)、刺耳音效与**敲门声惊吓**。请勿在公共场合或心脏不适、易受惊吓、患有光敏性疾病的人群中播放。游戏内不会标注"恐怖",以保证问卷体验,特此在发布页说明。

> **免责声明**:灰湖科技(GRAYLAKE)与 AI「GRAY-47(小灰)」均为**虚构**,与现实中的任何公司、组织、产品、AI 均无关联;本作品为纯文本创意展示,不含任何真实数据采集。

一款**纯文本**心理恐怖游戏。你收到灰湖科技《GRAY-47 用户满意度调查》问卷,评价陪伴型 AI「GRAY-47(小灰)」。全部为选择题。很简单。正常填写即可。

> 深夜 · 耳机 · 独处。预计 5–10 分钟。全程零图片,含真实敲门音效。

## 运行方式

双击 `index.html`(入口页)→「开始作答」;或直接双击 `game.html`。任意现代浏览器,无需联网、无需安装,手机可用。

## 操作

| 操作 | 说明 |
|---|---|
| 点击选项 | 全部交互均为选择题,选项即你的评价 |
| 右上角「静音」/ `M` 键 | 随时静音/恢复程序化环境音 |

## 游戏结构(无剧透)

- 白底问卷 UI,共 23 题。玩家是 GRAY-47 的普通用户,认真评价即可。
- **隐藏数值:抵触值**——你选过多少差评,它都知道。不上屏,不解释。
- **核心机制:差评即报复**。一旦你表达不满(不满意/生硬/烦躁/想退出…),问卷立刻以红字跳杀回敬,且越到后面越重:轻——"回答已同步。"中——"本问卷承诺不记录您的身份。承诺已更新。"重——"我们无法接受您的评价。请等待专员上门。"
- **结局是你行为的直接后果**:全程好评 → 平静的"感谢参与",无敲门;有差评 → 问卷感谢完,你的门响了。
- 无任何"你才是被测样本"之类的隐藏真相,无括号旁白,不揣测你的心理。

结局取决于你的**抵触值**(差评总数),分四档:

- **平静结局(抵触值 0)**:全程好评/中性。"感谢您参与本次调查。您的评价已归档。您的真实反馈,正是我们需要的。"没有敲门。
- **敲门 · 档 1(抵触值 1–3)**:感谢语结束后,门口响起三下轻敲。"门外没有人。"
- **敲门 · 档 2(抵触值 4–7)**:重敲四记,越来越急。"敲门声没有停。""门外的人没有离开。"
- **敲门 · 档 3(抵触值 8+)**:砸门 → 门被从外推开(吱呀)→ 脚步逼近 → "专员已到。您填写问卷时的位置,已被更新。"

门外的音效来自 Mixkit 免版权素材,已内嵌进 `game.html`,离线也能响。
