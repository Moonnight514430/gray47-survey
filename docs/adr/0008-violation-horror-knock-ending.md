# ADR-0008: 侵犯感恐怖——差评触发报复,敲门结局,真实音效内嵌

**Status**: accepted (supersedes ADR-0007)

**Context**: v2 的"玩家是被测样本"方向(样本档案、一致性分析、编号 47、永久黑幕)被评审否决:结局形式主义,依赖"事后细思"才成立的真相。v3 转向**实打实的侵犯感**。

**Decisions**:

1. **删除观察对象设定**:样本档案、一致性分析、第 47 位填写者、编号题全部移除;黑幕仅作重档报复的临时惊吓舞台,不再是"永久安全区崩塌"的隐喻。
2. **恐怖因果链显性化**:玩家表达不满(差评)→ 问卷立即报复跳杀。抵触值越高、进度越靠后,报复越重(三档:回答已同步 → 承诺已更新 → 专员上门)。开场"匿名"承诺在报复中被红字撕毁("承诺已更新")——侵犯感来自承诺与行为的反差,无需隐藏真相。
3. **结局是行为的直接后果**:抵触值为 0 → 平静结局,无敲门;有差评 → 敲门结局,敲门声按抵触值升级(轻敲三下 → 重敲不停 → 砸门破门 + 脚步逼近 + "专员已到")。玩家清楚自己为什么挨吓。
4. **引入真实音效**:`assets/音频/` 存放 Mixkit 免版权 mp3(敲-厚木门/重门关合/摔门重响/门开-恐怖吱呀/地板吱呀),以 base64 内嵌 `game.html`,保持单文件离线可播(任意 file:// / 托管方式);环境音乐仍由 Web Audio 程序化合成,静音可用 M 键或屏幕按钮。
