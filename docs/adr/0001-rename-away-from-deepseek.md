# ADR-0001: 弃用「DSH」,改名「GRAY-47 / 灰湖科技」

**Status**: accepted

初版游戏将 AI 命名为 DSH(DeepSeek-Horror)。评审发现:DeepSeek 为注册商标且知名度高,"DeepSeek-Horror"全称直接含商标词,缩写又与 DeepSeek 官方项目(DeepSeek Harness)撞车,公开部署在 GitHub 上存在商标混淆与搭便车风险。决定彻底去商标化:AI 改名「GRAY-47(小灰)」,厂商为虚构的「灰湖科技 GRAYLAKE」;"47"保留为终局"样本编号"的伏笔。代价是丢失原名的玩梗效果,但换来发布零风险。
