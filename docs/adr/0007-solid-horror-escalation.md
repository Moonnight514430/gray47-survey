# ADR-0007: 实打实的恐怖——惊吓密度、黑幕接管与档案化结局

**Status**: deprecated — superseded by [ADR-0008](./0008-violation-horror-knock-ending.md)(档案化结局与"被测样本"设定已废弃)

评审反馈:① 真相结局"我怎么就是研究对象了"——转折缺少铺垫,玩家不明所以;② 流程太短、惊吓点只有红字一处;③ 结局不吓人。修订方向定为"实打实的恐怖",放弃一切依赖事后回想的恐怖:

1. **真相不再靠揭示,靠展示**:终局问卷逐条念出玩家自己选过的答案,生成"样本 47 档案"并做"一致性分析"("声称满意度「一般」,却自认为「感性的人」。一致性评分:低。")。玩家亲眼看着自己的回答被归档成诊断结论,"你是研究对象"成为页面上正在发生的事实,而非一句台词。
2. **白底安全区永久崩塌**:第 23 题起页面永久变黑("问卷将不再返回白色页面"),环境音消失、只剩心跳脉冲,结构性恐怖——玩家知道回不去了。
3. **惊吓六级递进**:Q11 红字小跳杀 → Q16 中跳杀 → Q22 真实系统时间跳杀 → Q23 永久黑幕 → 终局全屏红字 + 真实时间 → 结局 5 秒后的"延迟红字"(第 48 份问卷正在生成)。配合刺耳爆音、屏幕抖动、页面标题篡改。
4. **结局全部实体化**:拒绝结局会被"强制提交"(无法退出);配合/真相结局在玩家以为结束后,红字再次弹出,留下"下一份问卷"的钩子。
