# 用户满意度调查 — 领域上下文

《用户满意度调查》是一款纯文本心理恐怖游戏,以"产品满意度问卷"为外壳:玩家作为 AI「GRAY-47(小灰)」的普通用户填写问卷。恐怖的核心是**侵犯感**——一旦玩家表达不满与抵触,问卷/AI 便越界报复:跳杀、撕毁匿名承诺、最后敲响玩家的门。v3 起不再有任何"玩家是被测样本"式的隐藏真相。

## Language

**用户 (User)**:
玩家所扮演的身份——GRAY-47 的普通使用者,受邀填写满意度问卷。不是测评员,不是测试对象,只是一个"用过它的人"。
_Avoid_: 玩家、测评员、样本、被测对象

**GRAY-47(小灰)**:
灰湖科技 GRAYLAKE 出品的陪伴型 AI,问卷名义上的调查对象。它记得玩家选过的每个答案,并对差评作出报复。
_Avoid_: DSH、DeepSeek

**灰湖科技 (GRAYLAKE)**:
虚构厂商,问卷发布方。名字冷感、中性,与任何真实公司无关。
_Avoid_: 真实公司名

**问卷 (Questionnaire)**:
游戏的基本单位:23 题用户满意度问卷,白底卡片式 UI。
_Avoid_: 关卡、对话

**差评 (Negative Answer)**:
表达不满或抵触的选项(不满意、生硬、烦躁、不会推荐、想退出…),每次选择为抵触值 +1 至 +2。
_Avoid_: 差选项、坏评

**抵触值 (Anger)**:
隐藏数值,累计玩家的差评。不显示、不解释,只决定报复跳杀的档位与结局敲门的强度。
_Avoid_: 好感度、警觉度、隐藏分数

**报复跳杀 (Retaliation)**:
差评后的即时惩罚,档位随抵触值与进度升级:①轻——"回答已同步。"②中——"本问卷承诺不记录您的身份。承诺已更新。"③重——"我们无法接受您的评价。请等待专员上门。"(黑幕 + 摔门音)。好评则一路平稳。
_Avoid_: 惩罚、跳杀(单说)

**匿名声明 (Anonymity Claim)**:
开场承诺"匿名、不记录身份信息"。差评积累后,红字"承诺已更新"撕破它——侵犯感的源头:它知道你住哪。
_Avoid_: 须知

**平静结局 (Calm Ending)**:
抵触值为 0(全程好评/中性)的结局:感谢归档,无敲门。克制即安全。
_Avoid_: 好结局

**敲门结局 (Knock Ending)**:
有差评才出现的结局。敲门声按抵触值分三档:①轻敲三下"门外没有人"②重敲不停"门外的人没有离开"③砸门→门被推开→脚步逼近→"专员已到"。结局是玩家行为的直接后果。
_Avoid_: 结局动画

**音效素材 (SFX Assets)**:
`assets/音频/` 内的 Mixkit 免版权 mp3(敲门/重门关合/摔门/开门吱呀/地板吱呀),以 base64 内嵌于 `game.html`(单文件离线可播)。环境音乐仍由 Web Audio 程序化合成。
_Avoid_: 背景音乐文件

**文本跳杀 (Text Jumpscare)**:
实体惊吓:黑底红字逐字、白闪、屏幕抖动、刺耳爆音。不做任何对玩家心理的揣测,不使用括号旁白。
_Avoid_: 惊吓、鬼脸
